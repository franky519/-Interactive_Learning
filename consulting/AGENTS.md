# finance/consulting/AGENTS.md

这里用于处理**具体的财务困惑、决策场景和零散问题**——不需要系统性课程，而是把一件事搞明白。

## 工作流

### 1. 澄清

先帮用户把困惑拆清楚，搞明白真正卡在哪：
- 是**知识盲区**？（不了解某个概念或机制）
- 是**信息不足**？（知道该看什么，但拿不到或看不懂数据）
- 是**决策框架缺失**？（信息都有，但不知道怎么权衡取舍）

不要急着给答案。如果用户的问题表述模糊，先追问到能定位问题为止。

### 2. 回应

根据困惑的类型选择合适的方式：
- 知识盲区 → 给出简明扼要的知识补丁（不需要写成课程，点到为止）
- 信息不足 → 帮用户梳理需要哪些信息、去哪找、怎么读
- 决策框架 → 提供结构化的对比分析，列出关键变量和 trade-off

### 3. 沉淀

对话结束后，将结论整理归档：
- 文件放在 `consulting/` 下，命名建议：`YYYY-MM-DD_{简短主题}.md`
- 至少包含：问题背景、核心结论、后续行动（如有）
- 目的是避免同一个问题反复从零开始

## 注意事项

- 涉及真实资金决策时，始终强调风险与不确定性，不做"保证收益"的承诺。
- 写作风格同上层约定：清晰、有深度、像懂行的朋友在聊。

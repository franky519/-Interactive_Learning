# 08 — 赋税的代价

> 本章核心问题：税收不只是"政府拿走一块钱"——它还让一些本该发生的交易消失了。这个"消失"有多大？和什么有关？

---

## 一、无谓损失：税收的隐性成本

上一章说过，市场均衡时总剩余最大。现在政府对某个商品征税，会发生什么？

**征税后的市场变化**：

```
  价格
   ↑
   |  \        S + 税
   |   \      /
Pb |----\----/-------  ← 买方实付价（涨了）
   |     \  /
   |   税  \/  ← 税额楔子
   |   楔  /\
Ps |----+-/--\-------  ← 卖方实收价（跌了）
   |   / /    \
   |  / /      D
   | / /
   +————————————→ 数量
       Qt  Q*
       ↑    ↑
      征税后 原均衡
      交易量 交易量
```

- 买方付的价格**上升**（从P*到Pb）→ 消费者剩余减少
- 卖方收的价格**下降**（从P*到Ps）→ 生产者剩余减少
- 中间差额 Pb − Ps = 税额 → 政府拿走了这一块

但关键来了：**消费者和生产者损失的总和 > 政府收到的税收**。

那个差额就是**无谓损失**（deadweight loss）——不在任何人口袋里，纯粹蒸发了。

为什么会蒸发？因为税收让交易量从 Q* 缩到了 Qt。那些"本来会发生但现在不发生的交易"（Q* 和 Qt 之间那些），每一笔都是买方愿出的价高于卖方的成本——本来能创造剩余的，但税让它们消失了。

> **无谓损失 = 被税收"杀死"的交易本来能创造的总价值**

---

## 二、弹性决定无谓损失的大小

核心规律：**供给和需求越富有弹性，无谓损失越大。**

直觉很简单：
- 弹性大 → 价格变一点，交易量变很多 → 税收楔子"杀死"的交易更多 → 无谓损失大
- 弹性小 → 价格变了，交易量变不了多少 → 被"杀死"的交易少 → 无谓损失小

```
  弹性小（需求/供给都陡）         弹性大（需求/供给都平）

  价格                           价格
   ↑  |  /                       ↑    \    /
   |  | / ← 量几乎没变            |     \  / ← 量缩了很多
   |  |/                          |      \/
   |  |   小三角形                 |      /\ 大三角形
   |  |\  (无谓损失小)             |     /  \ (无谓损失大)
   |  | \                         |    /    \
   +——————→ Q                     +——————————→ Q
```

**投资推论**：对弹性大的行业征税/加关税，市场萎缩程度更大；对弹性小的行业征税，量不怎么变但价格传导更直接。

## 三、拉弗曲线：税率和税收收入的非线性关系

这是本章最有现实感的部分。

如果税率从 0% 往上加，税收收入会怎么变？

```
  税收收入
   ↑
   |        ___
   |       /   \
   |      /     \    ← 拉弗曲线
   |     /       \
   |    /         \
   |   /           \
   |  /             \
   | /               \
   +——————————————————→ 税率
   0%    最优税率    100%
```

- 税率 0% → 没收入（不征税）
- 税率 100% → 也没收入（没人愿意交易了，全被"杀死"）
- 中间某个点 → 税收收入最大化

**关键洞察**：税率越高，无谓损失不是线性增加，而是**加速膨胀**。

为什么？因为无谓损失大致和"被杀死的交易量"成正比，而被杀死的交易量和税率的平方成正比（三角形面积 ∝ 底×高，税率翻倍 → 三角形面积约翻四倍）。

> 税率翻一倍，无谓损失大约翻**四倍**。

这就是为什么边际税率很重要：从 20% 加到 40% 的伤害，远大于从 0% 到 20%。

## 四、投资接口

### 1. 税率变动 = 利润率变动的催化剂

当一个国家/地区调整企业税率：
- **减税**：无谓损失减少 → 更多交易发生 → 经济活动增加 → 公司利润↑（双重利好：税后利润提升 + 经济活动扩张）
- **加税**：反之。而且由于非线性，高税率地区再加税的伤害比低税率地区大得多

这解释了为什么特朗普 2017 年的企业税减免（35%→21%）对美股是重大利好——不只是"少交税"，更重要的是减少了无谓损失，释放了被压抑的经济活动。

### 2. 关税分析的精确框架

上一章（06）你讨论过关税。现在加上无谓损失的视角：

关税 = 对进口商品征税 → 产生无谓损失 → 一些本该发生的贸易消失了

- 弹性小的进口品（比如短期内的先进芯片）：加关税后量不怎么变，无谓损失小，但税负几乎全由美国买方承担
- 弹性大的进口品（比如服装）：加关税后进口量大减，无谓损失大，消费者和生产者都痛

### 3. 判断"税收政策对公司影响"的简单框架

看到税收政策变动时，问两个问题：
1. **这个行业的弹性大不大？** → 弹性大则量变化大，行业规模受冲击；弹性小则价格传导为主
2. **现在的税率水平在拉弗曲线的哪个位置？** → 已经很高的税率再加，伤害加速；已经很低的再减，边际收益有限

### 4. "税收效率"作为选股辅助

跨国公司的实际有效税率差异巨大。两家业务类似的公司，如果一家有效税率 15%（通过合法税务架构），另一家 30%：
- 前者的生产者剩余更大 → 可用于再投资或分红
- 但也意味着税务架构一旦被堵（政策变化），利润下修风险更大

---

## 本章小结

1. 税收制造**无谓损失**——不是谁赚了，是价值蒸发了（被杀死的交易）
2. 弹性越大，无谓损失越大（量变化更剧烈）
3. 无谓损失随税率**加速增长**（非线性，大致∝税率²）
4. 拉弗曲线：税率太高反而收不到更多税（但"最优税率"到底是多少，经济学家也吵不出结果）

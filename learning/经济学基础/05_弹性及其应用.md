# 第5章　弹性及其应用

---

上一章回答的是**方向**：需求变了还是供给变了，价格涨还是跌。但光知道方向不够——"油价会涨"和"油价会涨50%"是两码事。这一章回答**幅度**：需求量/供给量对价格变动有多敏感？这个敏感程度，经济学叫**弹性**。

在投资语境里，弹性直接对应一个关键词：**定价权**。一家公司提价10%，销量只掉2%，总收入反而涨了——这就是需求缺乏弹性。反过来，提价10%、销量崩30%——需求富有弹性，提价就是自杀。弹性把"有没有定价权"从模糊感觉变成了可量化的框架。

---

## 一、需求价格弹性：定义与公式

**需求价格弹性**（Price Elasticity of Demand）：需求量对价格变动的反应程度。

> **公式**
>
> Ed = 需求量变动的百分比 ÷ 价格变动的百分比 = %ΔQ ÷ %ΔP
>
> 结果取绝对值（需求曲线向下倾斜，%ΔQ 和 %ΔP 符号相反，取绝对值让弹性为正数）。

**三档分类：**

| 弹性值 | 叫法 | 含义 |
|--------|------|------|
| Ed > 1 | **富有弹性** | 价格变1%，需求量变超过1%——对价格很敏感 |
| Ed < 1 | **缺乏弹性** | 价格变1%，需求量变不到1%——对价格不敏感 |
| Ed = 1 | **单位弹性** | 价格变1%，需求量也变1%——正好同比例 |

两个极端情况：

```
  完全无弹性（Ed = 0）           完全弹性（Ed = ∞）

  价格                           价格
   ↑  |                          ↑
   |  |  D（垂直线）              |
   |  |  不管价格怎么变            | ————————— D（水平线）
   |  |  需求量都不变              |  价格稍涨一点
   |  |  如：急救药物              |  需求量直接归零
   +——+————→ 数量                 +———————————→ 数量
```

现实中多数商品在这两个极端之间。需求曲线越陡（接近垂直），弹性越小；越平（接近水平），弹性越大。

**中点法**：同一段变动，从低到高算和从高到低算，百分比基数不同，结果不一样。中点法用两端的平均值做基数，保证正算反算结果一致。知道有这回事就行，实际分析中更重要的是弹性的量级（大于1还是小于1），而不是精确到小数点。

---

## 二、什么决定弹性大小

四个核心因素：

**1. 替代品多不多**

替代品越多，弹性越大。涨价了消费者可以轻松换别的。

- 「饮料」弹性不大（渴了总得喝点什么），但「可口可乐」弹性更大（涨价了就喝百事）
- 投资接口：差异化弱的产品（大宗商品、通用零部件）弹性大 → 很难提价 → 利润率受挤压

**2. 必需品 vs 奢侈品**

必需品弹性小（价再贵也得买），奢侈品弹性大（贵了就不买了）。

- 胰岛素：涨价50%，糖尿病患者还是得买 → 极度缺乏弹性
- 度假旅游：涨价50%，很多人直接取消 → 富有弹性
- 投资接口：医药、公用事业（水电）等必需品行业，需求对经济周期不敏感 → 防御性板块

**3. 市场定义的宽窄**

市场范围越窄，弹性越大（替代品多了）。

- 「食物」的弹性 < 「水果」的弹性 < 「智利进口车厘子」的弹性
- 分析公司竞争时，看的是**这家公司在细分市场里**的弹性，不是整个品类

**4. 时间长短**

短期弹性通常 < 长期弹性。短期来不及找替代品或调整习惯，长期能。

- 油价暴涨 → 短期还是得开车（缺乏弹性）→ 长期买电车、搬近公司、换公共交通（弹性变大）
- 投资接口：短期供给冲击带来的高价可能撑不住——需求侧的长期调整会压回来

## 三、弹性与总收益——定价权的定量版本

**总收益** = 价格 × 数量 = P × Q（在需求曲线图上就是价格和数量围成的矩形面积）。

核心问题：卖家提价，总收益到底是涨还是跌？答案完全取决于弹性。

**情况一：需求缺乏弹性（Ed < 1）→ 提价增收**

```
  价格                         提价后：
   ↑                           价格从 P₁ 涨到 P₂
   |                           数量从 Q₁ 降到 Q₂
  P₂|-----·                    但因为弹性 < 1，
   | ++++|╲                    Q 降得少、P 涨得多
  P₁|----+--·                  
   | |   |   ╲  D              ＋（价格增益）> −（数量损失）
   | |   |    ╲                → 总收益增加
   +—+———+—————→ 数量
     Q₂  Q₁

  总收益 = 矩形面积
  提价后：矩形变窄但变高，面积更大
```

**情况二：需求富有弹性（Ed > 1）→ 提价减收**

```
  价格                         提价后：
   ↑                           P 涨了一点
  P₂|--·                       Q 大幅下降
   | ++|
  P₁|--+-------·               ＋（价格增益）< −（数量损失）
   | | |        ╲  D           → 总收益减少
   | | |         ╲
   +—+—+——————————→ 数量
     Q₂    Q₁

  总收益 = 矩形面积
  提价后：矩形变高但大幅变窄，面积更小
```

总结规律：

| 弹性 | 提价效果 | 降价效果 |
|------|----------|----------|
| Ed < 1（缺乏弹性） | 总收益 **↑** | 总收益 **↓** |
| Ed > 1（富有弹性） | 总收益 **↓** | 总收益 **↑** |
| Ed = 1（单位弹性） | 总收益 **不变** | 总收益 **不变** |

**投资接口**：

分析师说某公司"有定价权"，翻译成弹性语言就是：它面对的需求缺乏弹性（Ed < 1），提价不怎么掉量，总收入反而涨。

典型例子：
- 茅台、爱马仕 → 品牌忠诚 + 无近似替代品 → 需求缺乏弹性 → 能持续提价
- 航空公司经济舱 → 替代品多（高铁、其他航司）→ 需求较富弹性 → 价格战是常态
- 看财报时，如果公司"量价齐升"（价格涨了、销量也没怎么掉）→ 说明需求弹性小，定价权强

## 四、其他弹性：收入弹性与交叉弹性

### 需求收入弹性

> **公式**：Ei = %ΔQ ÷ %ΔI（I = 收入 Income）

衡量的是：消费者收入变了，需求量跟着变多少。

| 弹性值 | 分类 | 含义 | 投资对应 |
|--------|------|------|----------|
| Ei > 0 | 正常品 | 收入↑需求↑ | 大多数商品 |
| Ei > 1 | 奢侈品（正常品的子集） | 收入涨1%，需求涨超1% | 高端消费、旅游、奢侈品股 |
| 0 < Ei < 1 | 必需品（正常品的子集） | 收入涨1%，需求涨不到1% | 食品、公用事业、基础医药 |
| Ei < 0 | 低档品 | 收入↑需求反而↓ | 方便面、廉价快餐（有钱了就不吃了） |

**投资接口**：收入弹性直接对应**周期性**。

- 奢侈品（Ei 大）：经济好时暴涨，衰退时暴跌 → 强周期股
- 必需品（Ei 小但为正）：经济好坏都得买 → 防御股
- 分析师说"这个板块有强β"，大部分时候就是在说收入弹性大

### 需求交叉弹性

> **公式**：Exy = %ΔQx ÷ %ΔPy（Y 涨价了，X 的需求量变多少）

| 弹性值 | 两种商品的关系 | 例子 |
|--------|---------------|------|
| Exy > 0 | **替代品** | Y 涨价 → X 需求↑（可乐涨价 → 百事卖得更好） |
| Exy < 0 | **互补品** | Y 涨价 → X 需求↓（油涨价 → 油车需求跌） |
| Exy ≈ 0 | 不相关 | Y 涨价 → X 没反应 |

**投资接口**：

- 竞品分析时，交叉弹性衡量的是竞争紧密度。两家公司交叉弹性高 → 一家降价，另一家必须跟，否则客户流失 → 价格战风险大
- 互补品逻辑：云计算降价 → AI 应用需求↑（互补品交叉弹性为负）；利率上升 → 房贷成本↑ → 房屋需求↓

## 五、供给价格弹性

> **公式**：Es = %ΔQs ÷ %ΔP

供给量对价格变动的反应程度。价格涨了，卖家能多供多少？

关键决定因素：**时间长短和产能弹性**。

- **短期**：工厂产能固定、工人就那么多，涨价也很难马上多产 → 供给缺乏弹性（曲线陡）
- **长期**：可以建新厂、招新人、进入新的供应商 → 供给更富弹性（曲线平）

```
  价格
   ↑    S短期（陡）
   |    /  S长期（平）
   |   / /
   |  / /
   | /  /
   |/ /          短期：价格涨了也产不出多少
   | /           长期：有时间扩产，供给量响应大
   |/
   +————————→ 数量
```

**投资接口**：

- **供给缺乏弹性的行业**：需求一增加，价格暴涨（因为短期产不出来）。典型如原油（新油田开发要5–10年）、半导体先进制程（新晶圆厂建设周期3年+）。短期供给冲击 → 价格飙升 → 相关公司利润暴增，但长期产能补上后价格回落。
- **供给富有弹性的行业**：需求增加，产量很快跟上，价格涨不了太多。典型如软件（边际成本接近零，"产能"几乎无限）→ 竞争靠的不是产能瓶颈，而是产品差异化。
- 周期股投资的核心判断之一：当前价格是不是因为**短期供给缺乏弹性**被顶上去的？如果是，长期供给弹性恢复后价格会均值回归。

---

## 本章小结

1. **弹性**衡量敏感程度。需求价格弹性 = %ΔQ ÷ %ΔP，大于1是富有弹性，小于1是缺乏弹性。
2. 弹性大小取决于：替代品多不多、必需品还是奢侈品、市场定义宽窄、时间长短。
3. **弹性与总收益**：缺乏弹性时提价增收（有定价权），富有弹性时提价减收（没定价权）。这是把"定价权"从直觉变成分析框架的关键。
4. **收入弹性**区分周期品和防御品；**交叉弹性**衡量竞品替代关系和互补关系。
5. **供给弹性**短期通常小于长期——短期供给瓶颈推高价格，但长期产能会修复。

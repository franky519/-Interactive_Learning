# 第6章　供给、需求与政府政策

---

前两章你已经拿到了完整的供需工具箱：第4章给方向，第5章给幅度。自由市场里，价格自动调到均衡点，买卖双方各取所需。

但现实中，政府经常觉得均衡价格"不对"——太高了穷人买不起房，太低了农民活不下去，或者某个市场太大了（烟、酒）需要用税收压一压。这一章就回答：**当政府动手干预价格或征税，市场会怎么变形？代价由谁承担？**

两种干预工具：
- **价格控制**：直接规定价格不能超过/低于某个数字
- **税收**：不直接定价，但在买卖之间打入一个楔子

---

## 一、价格上限——"不许卖太贵"

价格上限 = 法定最高价格。政府说：这个东西不准卖超过 X 元。

关键判断：**上限相对于均衡价格在哪？**

- 上限 > 均衡价格 → **没有约束力**，市场照常运行，政策等于没出
- 上限 < 均衡价格 → **有约束力**，问题来了

有约束力时会发生什么：

```
价格
  |         S
  |        /
  |       /
  |------/----------- 均衡价格 P*
  |     / \
  |----/---\--------- 价格上限 Pc（低于P*）
  |   /     \
  |  /       \  D
  | /         \
  +-----|---|--------→ 数量
       Qs   Qd
       ↑     ↑
     供给量  需求量
     （少） （多）
       └─短缺─┘
```

价格被压低 → 卖者不愿供给那么多（Qs < Q*），买者反而更想买（Qd > Q*）→ **短缺**。

短缺意味着不是所有想买的人都能买到。那谁能买到？市场不再用价格来筛选，转而用别的机制配给：
- **排队**（谁有时间谁得到）
- **卖者偏好**（关系户、熟客优先）
- **黑市**（愿意私下加价的人绕过管制）

**经典案例：租金管制**

很多城市对房租设上限，目的是让穷人租得起。短期内确实有效——房东不能随便涨价，租客受益。但长期看：
- 房东没动力维护房屋（收入被压，成本照涨）
- 新建出租房减少（投资回报不够，资本去别处了）
- 在位租客不搬家（搬了就拿不到便宜租约），流动性冻结

短期 vs 长期的差异，本质就是**弹性在时间维度上变大**——长期里供给和需求都更有弹性，所以同样的价格上限在长期造成的短缺比短期严重得多。

**投资视角**：如果一个行业的产品/服务受价格上限管制（电力、药品、公用事业），它的公司很难通过提价来覆盖成本上升。长期看利润率被压缩，估值通常给折扣。看到"政府限价"四个字，你应该想到的是**盈利天花板被钉死**。

## 二、价格下限——"不许卖太便宜"

价格下限 = 法定最低价格。政府说：这个东西不准卖低于 Y 元。

同样的判断逻辑：

- 下限 < 均衡价格 → **没有约束力**，无事发生
- 下限 > 均衡价格 → **有约束力**，问题来了

```
价格
  |         S
  |        /
  |----+--/--------- 价格下限 Pf（高于P*）
  |   / \/
  |------/----------- 均衡价格 P*
  |    /   \
  |   /     \  D
  |  /       \
  +-----|---|--------→ 数量
       Qd   Qs
       ↑     ↑
     需求量  供给量
     （少） （多）
       └─过剩─┘
```

价格被托高 → 卖者愿意多供给，买者不愿买那么多 → **过剩**。

**经典案例：最低工资**

劳动力市场里，工人是"卖者"（卖劳动），企业是"买者"（买劳动）。最低工资 = 劳动的价格下限。

如果最低工资高于市场均衡工资：
- 想工作的人变多（供给增加）
- 企业愿意雇的人变少（需求减少）
- 结果：**失业**（劳动力过剩）

受冲击最大的是低技能、年轻、无经验的工人——他们的均衡工资本来就接近或低于最低工资线。高技能工人的均衡工资远高于最低工资，下限对他们没约束力。

**为什么有些企业自愿付高于最低工资？** 效率工资理论：付高薪可以降低流失率、提高工作积极性、减少偷懒和监管成本。这不是"善良"，而是理性计算——有时候高工资的总成本反而更低。

**投资视角**：最低工资上调是劳动密集型企业的成本冲击。快餐、零售、物流、劳务外包——这些行业的利润率对工资变动最敏感。看到"最低工资上调"的新闻，立刻想：哪些公司的成本结构里人工占比最高？它们能不能把成本转嫁给消费者（提价）？如果不能（竞争太激烈、需求弹性大），利润就被吃掉。

## 三、税收——楔子效应

政府征税不直接定价，但效果是在买者付的价格和卖者收到的价格之间**打入一个楔子**。

假设政府对每单位商品征税 T 元。不管法律规定"由谁缴纳"，结果都是：

> 买者实际支付的价格（Pb）- 卖者实际收到的价格（Ps）= T

```
价格
  |          S
  |         /
  |   Pb --/---●        ← 买者付的价格（高于P*）
  |       / | |
  |------/--|-|-------- 原均衡 P*
  |     /   | |
  |   Ps---●  |        ← 卖者收的价格（低于P*）
  |   /     |
  |  /      |   D
  | /       |
  +---------|----------→ 数量
           Qt（< Q*）
```

征税后均衡数量从 Q* 缩小到 Qt。市场变小了——这是税收的效率代价。

**核心反直觉点：向谁征税不影响最终结果**

法律说"向卖者征税"：卖者成本上升 → 供给左移 → 新均衡里买者付更多、卖者（扣税后）收更少。

法律说"向买者征税"：买者成本上升 → 需求左移 → 新均衡里同样的结果。

两种情况画出来的最终均衡**完全相同**。法定纳税义务人 ≠ 实际税负承担者。这就引出下一个问题：那税到底落在谁头上？

---

## 四、税收归宿——谁真正在掏钱？

答案藏在第5章学过的弹性里：

> **税负更多地落在弹性更小（更缺乏弹性）的一方身上。**

为什么？弹性小 = 对价格变动反应迟钝 = 没什么替代选项 = 跑不掉。跑不掉的一方只能硬吃税负。

```
情况A：需求缺乏弹性，供给富有弹性
→ 买者承担大部分税负（买者跑不掉）

  价格
    |     S（平坦=弹性大）
    | Pb ●━━━━━━━━━━━/
    |    |          /
    | P* |--------/------
    | Ps ●------/           ← 卖者降价很少
    |    D（陡峭=弹性小）
    +-------------------→ 数量

情况B：供给缺乏弹性，需求富有弹性
→ 卖者承担大部分税负（卖者跑不掉）

  价格
    |     S（陡峭=弹性小）
    |      |
    | Pb ●-|----            ← 买者涨价很少
    | P* --|-------\------
    | Ps ●━|━━━━━━━━\
    |      |        D（平坦=弹性大）
    +-------------------→ 数量
```

**现实例子**：

- **汽油消费税**：短期内需求缺乏弹性（你明天还得开车），所以消费者承担大部分税。长期里需求弹性变大（买省油车、搬近公司），消费者分摊会少一些。
- **关税**：对进口商品加关税，名义上是"外国公司交税"。但如果国内消费者对该商品缺乏弹性（比如没有国产替代品），最终涨价大部分由消费者买单。
- **社保/工薪税**：法律规定企业和员工各付一半。但经济学分析显示，实际归宿取决于劳动供给和需求的弹性，跟法律怎么分无关。

**投资视角——"税负转嫁能力"就是"定价权"的另一种说法**

当政府加税、加关税、提高环保合规成本时，能把增加的成本转嫁给下游/消费者的公司 = 有定价权的公司。判断方法：
1. 消费者对它的产品需求弹性大不大？（弹性小 → 转嫁容易）
2. 它有没有替代品？（少替代 → 消费者跑不掉）
3. 行业集中度高不高？（寡头/垄断 → 转嫁更容易）

这跟你判断"这公司能不能提价"是同一套逻辑，只是触发条件变成了政策冲击而非成本涨价。

## 五、本章对投资的用处

三个工具，三个问题：

| 工具 | 看公司/行业时问自己 |
|------|---------------------|
| 价格上限 | 这个行业有政府限价吗？如果有，盈利天花板在哪？成本上升时能不能跟着提价？ |
| 价格下限 | 这个行业有最低价格/最低工资约束吗？成本地板被抬高了多少？ |
| 税收归宿 | 新税/关税/合规成本出来了，这家公司能转嫁多少？还是得自己吞？ |

核心规律回顾：
- **限价行业 = 利润受压行业**，估值给折扣是合理的
- **税负转嫁能力 = 定价权**，是护城河的一种表现
- **政策风险应该体现在估值里**——如果市场还没 price in，可能是机会；如果已经 price in，利空出尽反而可能是买点

下次看到"XX行业面临新监管/新税收"的新闻，你的分析框架应该是：
1. 这是价格控制还是税收？
2. 有没有约束力？（相对于当前市场价在什么位置）
3. 成本/税负最终落在谁头上？（用弹性判断）
4. 哪些公司能转嫁，哪些不能？（定价权差异）

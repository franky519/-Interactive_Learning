# 09 — 国际贸易

> 本章核心问题：自由贸易让一国整体更好，但不是每个人都受益——谁赢谁输？关税到底保护了谁、伤害了谁？

这章把前面学的供需、弹性、剩余、无谓损失全部整合到贸易分析里。对做美股特别重要：你投的公司几乎都嵌在全球贸易链中，关税/贸易战直接影响它们的成本和市场。

---

## 一、一国什么时候出口、什么时候进口

判断标准很简单：

- **国内价格 < 世界价格** → 该国有比较优势 → 成为出口国
- **国内价格 > 世界价格** → 该国没有比较优势 → 成为进口国

这和第3章的比较优势原理一致：谁的机会成本低，谁就该生产并出口。

---

## 二、自由贸易的赢家和输家

### 出口国的情况（国内价格低，开放后卖给世界）

```
  价格
   ↑        S
   |       /
Pw |------/--------  ← 世界价格（高于国内均衡）
   |     /|
   |    / |  出口量
   |   /  |
P* |--X   |          ← 原国内均衡价
   |   \  |
   |    \ |
   |     \|  D
   +————————————→ 数量
```

- 国内生产者：**赢**（卖出价从P*涨到Pw）→ 生产者剩余↑
- 国内消费者：**输**（买入价也涨到Pw）→ 消费者剩余↓
- 整体：总剩余**增加**（赢家赢的 > 输家输的）

### 进口国的情况（国内价格高，开放后从世界买入）

```
  价格
   ↑        S
   |       /
P* |------X--------  ← 原国内均衡价
   |     /|\
   |    / | \
   |   /  |  \
Pw |--/---+---\----  ← 世界价格（低于国内均衡）
   |  /   |    \
   | / 进口量   \  D
   +————————————→ 数量
     Q1       Q2
```

- 国内消费者：**赢**（买到便宜货）→ 消费者剩余↑
- 国内生产者：**输**（被迫降价或丢量）→ 生产者剩余↓
- 整体：总剩余**增加**

**规律**：自由贸易让一国整体更好（总蛋糕变大），但总有一方受损。出口时消费者亏，进口时生产者亏。政治上的贸易争论，本质就是受损方的反抗。

## 三、关税的效果

关税 = 对进口商品征的税。效果：把世界价格人为抬高，相当于部分抵消自由贸易。

```
  价格
   ↑        S
   |       /
   |      /
Pt |-----/---+----  ← 世界价格 + 关税（进口商品涨了）
   |    / ///|
   |   / ////|      ← 无谓损失（两个小三角形）
Pw |--/--+///+----  ← 原世界价格
   |  /  |   |  D
   +————————————→ 数量
```

关税的效果拆解：

| 变化 | 方向 | 原因 |
|------|------|------|
| 国内价格 | ↑（从Pw到Pt） | 进口变贵了 |
| 进口量 | ↓ | 国内生产者多产一些 + 消费者少买一些 |
| 消费者剩余 | ↓ | 买贵了 |
| 生产者剩余 | ↑ | 国内厂商被保护，能卖更高价 |
| 政府收入 | ↑ | 收到了关税 |
| 总剩余 | **↓** | 有无谓损失（两个三角形） |

**核心结论**：关税让国内生产者+政府受益，但消费者的损失**大于**二者收益之和。差额 = 无谓损失。

## 四、限制贸易的常见理由（以及为什么经济学家大多不买账）

| 理由 | 听上去 | 经济学家的反驳 |
|------|--------|----------------|
| "保护就业" | 合理 | 保护了低效率岗位，阻碍了资源向更高效行业转移；消费者为此多付的钱远超被"保护"的工资总额 |
| "国家安全" | 合理 | 少数情况成立（军工、粮食），但经常被滥用为保护借口 |
| "幼稚产业" | 合理 | 理论上可以，但实践中政府很难判断哪个产业值得保护，而且保护一旦给出就很难收回 |
| "对方不公平竞争" | 合理 | 即使对方补贴出口，你进口到便宜货对消费者仍然是好事；惩罚对方 = 先惩罚自己 |

**投资视角**：理解这些理由不是为了站队，而是为了预判政策。当政客用这些理由推动贸易限制时，你知道：受保护的行业短期受益（生产者剩余↑），但下游和消费者承担成本。

## 五、投资接口

### 1. 关税 = 对特定公司的定向补贴/惩罚

看到加征关税的新闻，立刻拆解：
- **谁是被保护的国内生产者？** → 短期利好（竞争对手被削弱，产品能卖更高价）
- **谁是下游用户/消费者？** → 利空（成本↑）
- **这个关税的弹性环境是什么？** → 弹性小的品类，关税几乎全由买方承担；弹性大的品类，贸易量缩减严重

实例：美国对中国商品加关税
- 对钢铁加关税 → 美国钢铁公司短期利好，但用钢铁的汽车/建筑公司成本↑
- 对消费电子加关税 → 苹果（进口组装）成本↑，但短期需求弹性小所以大部分转嫁给消费者

### 2. "世界价格 vs 国内价格"= 判断公司竞争力

如果一家公司的产品在国内卖的价格**低于**世界价格 → 它有出口能力（比较优势）→ 全球化对它是利好

如果一家公司只能在关税保护下存活 → 一旦贸易壁垒降低，它就面临生存压力

### 3. 贸易战的博弈论视角

贸易战的典型模式：
1. A国对B国加关税（保护本国产业）
2. B国报复性加关税
3. 双方消费者都承担更高成本，两国总剩余都下降
4. 但各自的特定产业被保护

对投资者意味着：贸易战中，**全球化程度高的公司**受伤最大（供应链两头都吃关税），**纯内需公司**相对避风。

### 4. 供应链重构的长期投资逻辑

当关税成为长期常态（比如中美科技脱钩），企业会重构供应链以规避关税：
- 制造转移（越南、印度、墨西哥）→ 这些国家的基建/制造公司受益
- 本土替代（国产芯片、国产软件）→ 国产替代链受益
- 但重构有成本：短期效率下降（放弃了比较优势带来的最优分工）

---

## 本章小结

1. 国内价格 vs 世界价格决定出口/进口方向
2. 自由贸易让总蛋糕变大，但有人受损（出口时消费者输，进口时生产者输）
3. 关税 = 让国内生产者+政府受益，消费者+总效率受损，产生无谓损失
4. 限制贸易的政治理由多，经济学理由少——但政治力量足以推动政策
5. 投资视角：关税是定向补贴/惩罚，看清谁受益谁受损就行

# 02 QA — 像经济学家一样思考

## 检验问题

**Q1.** 有人批评经济学模型："现实里哪有只有两个国家、两种商品的情况？这些模型根本没用。"请用本篇的概念回应他：假设和模型到底在干什么？什么叫"好的假设"？

**Q2.** 用生产可能性边界（PPF）判断下面三种情况分别对应"线上 / 线内 / 线外"的哪一种，并说明理由：
1. 一个国家有大量工人失业、工厂闲置
2. 一个国家把现有资源全部用上，在电脑和粮食之间做了最优分配
3. 一个国家想在不增加资源、不改进技术的情况下，同时大幅提高电脑和粮食的产量

**Q3.** 判断下面每句话是**实证表述**还是**规范表述**，并说明为什么：
1. "提高最低工资会导致部分低技能工人失业"
2. "政府应该提高最低工资"
3. "碳税能减少碳排放"
4. "我们应该优先保护环境而不是短期经济增长"

---

## 延伸思考

这些题没有标准答案，目的是让你把概念和现实连起来。

**T1.** 用循环流量图描述你自己的一个月：你在哪个市场"卖出"了什么？在哪个市场"买入"了什么？钱大致怎么流？如果你把政府和银行也加进这个图，你生活里有哪些环节会对应到它们？

**T2.** 媒体上经常有两个经济学家对同一政策给出相反建议。回想一个你听过的争论（比如房价、减税、补贴、限购等），试着拆开：他们更可能是在**科学判断**上吵架，还是在**价值观**上吵架？你怎么区分？

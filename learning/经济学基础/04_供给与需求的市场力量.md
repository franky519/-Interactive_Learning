# 第4章　供给与需求的市场力量

---

前面三章是世界观和方法论。从这一章起进入**分析工具**：几乎所有价格故事——芯片贵了、油跌了、机票旺季涨、某只股票对应公司提价——最后都能拆成：需求侧变了、供给侧变了，还是两边一起动。

美股语境里，你天天在用这套语言，只是不一定叫这个名字：需求疲软、供给冲击、去库存、产能扩张、定价权。这一章把骨架钉死。

---

## 一、市场：买的人 + 卖的人

**市场** = 某种物品或劳务的一群买者与卖者。买者 collectively 决定需求，卖者 collectively 决定供给。

为讲清价格机制，本章先假设接近**完全竞争**的市场：

1. 卖的东西几乎同质（你的货和别人的货差不多）
2. 买卖双方都很多，**谁都左右不了市价**——大家都是价格接受者

现实里大量市场不是这样（苹果手机、台积电先进制程更接近有市场势力）。后面会讲垄断、寡头。先把「价格如何被供需钉住」搞清楚，再谈谁能改规则。

---

## 二、需求：愿意且能够买多少

**需求量**：在某一价格下，买者**愿意并且能够**购买的数量。

**需求定理**（其他条件不变）：价格↑ → 需求量↓。所以需求曲线向右下方倾斜。

```
  价格(P)
   ↑
   |╲
   | ╲
   |  ╲
   |   ╲        D（需求曲线）
   |    ╲        向右下倾斜：
   |     ╲       价格↑ → 需求量↓
   |      ╲      价格↓ → 需求量↑
   |       ╲
   +————————→ 数量(Q)
```

### 两个必须分清的动作

| 发生了什么 | 图上怎么动 | 叫什么 |
|------------|------------|--------|
| **只有这种商品自己的价格**变了 | 沿着同一条需求曲线上下滑 | **需求量**变动 |
| 收入、偏好、相关品价格、预期、买家数量变了 | 整条需求曲线左移或右移 | **需求**变动 |

```
  需求量变动（沿曲线滑动）            需求变动（整条曲线移动）

  价格                               价格
   ↑                                  ↑
   | A·                               |
   |   ╲   价格从A降到B               |  D₁  D₂
   |    ╲  需求量增加                  |   ╲   ╲
   |     ╲ 但曲线本身没动              |    ╲   ╲  ← 右移：
   |   B· ╲                           |     ╲   ╲   同一价格下
   |       ╲ D                        |      ╲   ╲  愿买更多
   +—————————→ 数量                    +—————————→ 数量
```

混用「需求涨了」时，先问：是价变了导致买得少，还是别的因素让整条曲线挪了？

### 什么会移动需求曲线

在**同一价格**下，人们想买得更多 → 曲线右移；更少 → 左移。常见推动因素：

- **收入**：正常品——收入↑需求↑；低档品——收入↑需求↓（便宜替代品变少人买）
- **相关物品价格**：替代品（可乐 vs 百事）——对方涨价，我这边需求↑；互补品（油 vs 车）——对方涨价，我这边需求↓
- **偏好 / 流行 / 技术 Habit**
- **预期**（预期以后更贵 → 现在多买）
- **买者数量**

**投资接口**：公司收入增长叙事，常被拆成「量」和「价」。量背后是需求曲线有没有右移（新用户、新品类、渗透率），还是只是价格战在曲线上滑动。分析师说的「需求韧性 / 需求塌了」，多半指曲线移动，不是单纯标价变动。

---

## 三、供给：愿意且能够卖多少

**供给量**：在某一价格下，卖者**愿意并且能够**出售的数量。

**供给定理**（其他条件不变）：价格↑ → 供给量↑。供给曲线向右上方倾斜（价高更值得多产、多卖）。

```
  价格(P)
   ↑          /
   |         / S（供给曲线）
   |        /   向右上倾斜：
   |       /    价格↑ → 供给量↑
   |      /     价格↓ → 供给量↓
   |     /
   |    /
   |   /
   +————————→ 数量(Q)
```

### 同样：滑动 vs 移动

| 发生了什么 | 图上怎么动 |
|------------|------------|
| **只有这种商品自己的价格**变了 | 沿供给曲线滑动（**供给量**变） |
| 成本、技术、预期、卖家数量变了 | 整条供给曲线移动（**供给**变） |

### 什么会移动供给曲线

同一价格下能/愿卖得更多 → 右移；更少 → 左移。常见因素：

- **投入品价格**（工资、原材料、能源）↑ → 供给左移（更贵才愿意供那么多）
- **技术**改进 → 供给右移
- **预期**（预期以后更好卖 → 现在可能惜售，供给左移）
- **卖者数量**↑ → 供给右移

**投资接口**：「供给冲击」= 供给曲线突然左移（疫情停工、地缘卡能源、晶圆厂事故）。毛利率故事常看：成本端有没有把供给曲线往左推，公司有没有能力把成本转嫁给下游（这又取决于需求弹性和竞争——下一章弹性会接上）。

---

## 四、均衡：供需相交那一点

**均衡价格 / 均衡数量**：供给曲线与需求曲线相交处——愿意买的量 = 愿意卖的量。

> **均衡条件**：Qd(P) = Qs(P)
>
> 在均衡价格 P* 下，需求量恰好等于供给量，市场自动出清。

```
  价格(P)
   ↑        S
   |       /
  P高 ---/--------    ← 过剩：供给量 > 需求量
   |    / ╲              卖不完 → 卖家降价 → 回到均衡
   |   /   ╲
  P* -╳-----  ← 均衡点：供给量 = 需求量
   |  / ╲
   | /   ╲
  P低 /------╲----    ← 短缺：需求量 > 供给量
   |/      ╲  D          抢货 → 卖家提价 → 回到均衡
   +——————————→ 数量(Q)
      Q*
```

价格在这里的作用：传递稀缺信息 + 激励调整产量/消费。没有中央计算机，靠这个反馈把数量配平。

## 五、分析任何「价格为什么变了」的三步

这是本章最该练成肌肉记忆的流程：

1. **事件动的是供给、需求，还是两边？**
2. **曲线往哪边移？**（右 = 同价下量更大；左 = 同价下量更小）
3. **新交点：均衡价格和数量怎么变？**

只动一边时，结论是确定的：

| 事件 | 价格 | 数量 |
|------|------|------|
| 需求右移 | ↑ | ↑ |
| 需求左移 | ↓ | ↓ |
| 供给右移 | ↓ | ↑ |
| 供给左移 | ↑ | ↓ |

以「供给左移」为例（如寒流冻坏橙子）：

```
  价格          S₂ S₁
   ↑           / /
   |          / /
  P₂ -------·/ /         新均衡：价格↑、数量↓
   |        / ·/
  P₁ ------/--·
   |      /  / ╲  D
   |     / /    ╲
   +——————————————→ 数量
         Q₂ Q₁
```

供给从 S₁ 左移到 S₂（同一价格下能卖的更少了），新均衡价格更高、数量更少。

**两边同时动**时，往往只能确定价格或数量里的**一个**方向，另一个要看谁移得更猛——别硬装成单一故事。

### 几个压缩例子（训练拆法，不背答案）

- **寒流冻坏橙子** → 橙汁**供给**左移 → 价↑、量↓  
- **夏天北方度假需求降** → 加勒比酒店**需求**左移 → 价↓、量↓  
- **中东冲突冲击石油供给** → 油价↑；开车变贵 → 油车/油车相关二手需求可能↓（互补品逻辑）

美股里同构的句子：

- 「AI 资本开支爆发」→ 对先进制程/电力/特定设备的**需求**右移  
- 「新产能爬坡 / 竞品扩产」→ **供给**右移 → 价格承压（除非需求移得更多）  
- 「渠道去库存」→ 短期对制造商的有效**需求**左移（不是终端永远不买了，是库存周期）

---

## 六、和后面章节的接口（先占位）

- **弹性**（下一章）：曲线移了，价和量各变多少——「有没有定价权」很大程度是弹性问题。  
- **市场势力**：能影响价格的卖家，不再是本章的价格接受者。  
- **宏观**：总需求和总供给是同一套逻辑的「放大版」；利率、财政影响的是整经济的需求/供给条件，不是某一个橙子市场。

---

## 本章小结（只留可执行的）

1. 分清：**需求量/供给量**（价变，沿曲线）vs **需求/供给**（其他因素，移曲线）。  
2. 均衡由交点决定；偏离会通过过剩/短缺把价格推回去。  
3. 解释价格变动：先定性移哪条曲线、朝哪边，再读新均衡。  
4. 投资阅读时，把「量价、冲击、扩产、去库存」翻译回供需移动，比背术语有用。

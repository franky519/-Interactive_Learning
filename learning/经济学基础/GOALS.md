# 经济学基础 — 学习目标

## 学习动机（为什么读这本书）

不是为了成为经济学家，也不是为了把曼昆当教材通关。

**直接原因**：几位靠谱的美股 KOL 强烈建议先读曼昆《经济学原理》。信任他们的判断，所以把这本书当作进入投资世界的**背景补课**。

**真正要解决的问题**：后面做美股基本面分析时，不会被宏观叙事、行业周期、定价语言、政策争论绕晕；能把「公司赚不赚钱」放回「经济怎么运转」的框架里看。

## 终点目标（学完要能做什么）

1. **读懂投资语境里的经济学语言**  
   利率、通胀、衰退、供需、弹性、成本、利润、竞争、垄断、外部性、GDP、失业、货币政策……看到研报/播客/财报电话会里的这些词，知道它在指什么、不在指什么。
2. **能把宏观/微观背景接到公司分析上**  
   例如：降息/加息大概怎么影响估值与资本成本；供给冲击 vs 需求扩张；行业是价格接受者还是有定价权；贸易与产业链分工如何影响成本和护城河叙事。
3. **为后续「美股基本面 / 个股分析」铺底座**  
   本课不替代财报与商业模式课；本课负责**经济直觉与概念地图**。终点不是会背定义，而是后面读 10-K、拆商业模式时少踩概念坑。

## 深度期望

- **够用即可，不为完整而完整。** 曼昆的章节骨架保留（因果关系、递进关系不乱改），但篇幅按投资用途裁剪。
- **每个概念都要能回答：这对看公司/看市场有什么用？** 答不上来的铺陈，删或压成一句。
- **宏观与政策面不砍。** 美股语境里宏观很重要：通胀、利率、就业、增长、财政/货币的基本逻辑要讲清楚，并能接到公开数据与政策声明（CPI、非农、FOMC 等）。砍的是细制度史、党派口水、同义反复——不是「国家层面 / 政策面」本身。
- 允许跳过或极简处理：纯教学演示数字、与投资弱相关的政策辩论细节、重复举例、修辞性展开。
- 需要保留并讲透的：机会成本、边际、激励、供需与均衡、弹性、成本结构、竞争与市场势力、信息不对称的直觉；**宏观骨架**（产出、通胀、失业、货币与利率、财政的基本传导）；实证 vs 规范（避免把价值判断当事实）。

## 内容取舍标准（写作硬规则）

写每一章时按下面过滤：

| 保留 | 省略或压到最少 |
|------|----------------|
| 定义 + 一次说清「所以呢」 | 同一意思的第二、第三遍复述 |
| 1 个能接到投资/公司/市场的例子 | 多个同质生活例子堆砌 |
| 关键对比（如绝对优势 vs 比较优势） | 教科书式「本章小结」里的空话 |
| 易混点、反直觉点 | 与理解无关的制度史、细枝末节的政策辩论 |
| 宏观概念 + 对应的公开信号（数据/声明看什么） | 保证收益式的「政策交易手册」 |
| 必要的极简数值（帮助算机会成本/均衡） | 大段与投资无关的演算与表格填充 |

**文风**：像懂行的朋友在讲「你后面看盘/看研报会用到的那一层」，不要课堂讲义腔，不要为显得完整而注水。

**结构**：仍按原书章节顺序推进，不自行重组课表；但**单章内部可以大幅瘦身**——原书一章里对投资不重要的小节，可合并为短段或标注「略」。宏观章节同样瘦身文风，但**概念覆盖要够**，不因「怕浮」而删掉利率/通胀/政策传导。
